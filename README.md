# week9-day2-counter-app

small project made while learning the Context API and state management. This is a simple counter app that stores its value inside a Context Provider so child components can access and update it without prop drilling.

How to run:

```bash
npm install
npm run dev
# build for production
npm run build
```

What I practiced:

- React Context API
- basic Tailwind layout
- small component structure

Notes: realistic student learning project. No external APIs.
